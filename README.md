# Поиск нор на видео

Локальный интерфейс для поиска возможных нор грызунов на фото или видео поля. Исходное видео и результаты не отправляются на серверы в интернете. Интернет используется только для установки пакетов и загрузки готовых весов. **Проверка реальной модели в этом окружении не завершена: веса скачать не удалось. До проверки с настоящими весами программа не может считаться полностью проверенной.**

## Запуск на Windows 10/11

1. Установите Python 3.9–3.13 с python.org, включив добавление в PATH. Нужны свободное место и подключение к интернету для первой установки.
2. Распакуйте проект и дважды нажмите `run.bat`. Первый запуск установит зависимости и попытается скачать модель; повторные запуски используют установленное окружение и проверенный файл модели. Браузер откроется автоматически; если порт 8000 занят, выбирается свободный порт.
3. Если модель не загрузилась, скачайте только [best_epoch_weights.pth](https://zenodo.org/records/17491180/files/best_epoch_weights.pth?download=1) и положите в `model_data\best_epoch_weights.pth`, затем нажмите «Проверить снова». Файл должен иметь размер 146818258 байт и MD5 `dd49f63c0e1eba57654eb42585c1da06`. Не скачивайте набор данных и отдельные веса базовой сети.
4. Нажмите «Загрузить материал» и выберите фото JPG/PNG или видео MP4/AVI/MOV. Обработка запустится автоматически, как только модель будет готова. Результат появится на экране; после завершения его можно скачать. Порог уверенности — 35%, размер анализа — 600, анализируется каждый кадр. На CPU обработка может идти заметно медленнее исходного видео. Остановка завершается после текущего кадра; доступна обработанная часть видео.
5. Закройте окно программы или нажмите Ctrl+C в консоли для завершения. Закрытие только вкладки браузера не прекращает обработку; откройте страницу снова или используйте кнопку остановки. Исходные звук и метаданные в результат не переносятся. Временные файлы расположены в `work/` и удаляются при выборе другого материала; при аварийном завершении их можно удалить вручную, когда программа закрыта.

Модель обучена на конкретных снимках пастбищ сверху: качество зависит от условий, норы могут пропускаться и возможны ложные срабатывания. 100% обнаружение не гарантируется.

## Источники и лицензии

Архитектура: [yeshushahua/CSPS_RetinaNet](https://github.com/yeshushahua/CSPS_RetinaNet), MIT, текст в `LICENSE`. Веса: [Gannan Grassland Rodent Burrow Detection](https://zenodo.org/records/17491180), CC BY 4.0; авторство и условия указаны на странице набора. Шрифт DejaVu Sans и его лицензия находятся в `assets/fonts/`. Веса в проект не включены.

## Выполненные проверки (Linux, Python 3.11)

* 17 ноября 2026: обращение к Zenodo завершилось ошибкой TLS в ограниченной среде; получено 0 МБ, проверка MD5 и совместимости `strict=True` с реальными весами невозможна. Скачиватель выполнил три попытки и сообщил путь для ручной установки.
* Запущен FastAPI; HTTP-ответ интерфейса 200. Три синтетических видео по 5 кадров, 160×120, 25 кадров/с (MP4, AVI, MOV) приняты и прочитаны; MJPEG первого кадра получен для каждого. Сброс сработал. Неподдерживаемое расширение и повреждённый MP4 дали понятные ошибки 400; без модели запуск отклонён (409).
* Проверены кэш якорей (повторно возвращается тот же тензор), обработка одной рамки NMS, серая заливка letterbox и нормализация. Ручной вызов отрисовки рамки с «Нора 84%» изменил изображение; файл шрифта содержит глифы кириллицы. Визуальная проверка не выполнялась.
* `run.bat`: UTF-8 без BOM, 43 строки CRLF, одиночных LF нет. Исполнение в Windows и проверка синтаксиса в cmd.exe не проводились.
* **Не проверено:** реальный инференс, распределение уверенности и срабатывания на фотографиях нор, точные рамки на полевых изображениях, скорость CPU, полная обработка, остановка и скачивание видео, работа управления в браузере и установка в Windows. Реального полевого видео не было. Протестировать это можно только после получения весов и запуска на целевой машине.

* Дополнительная проверка нового интерфейса: через HTTP приняты синтетические JPG и PNG, выдан первый кадр MJPEG, повреждённый PNG отклонён; MP4 поставлен в ожидание модели. Автоматический запуск и результат с реальными весами по-прежнему не проверены.
